# 주제
Naver 검색 API("search/**") 기반 Single Activity + navigation-compose APP

# 기술 스택

- **구조**: Single Activity + navigation-compose, MVI
- **기본**: Kotlin, coroutines(Flow)
- **UI**: 100% compose, material3
- **DI**: Hilt

# 특징

- 싱글 엑티비티 + 네비게이션 컴포즈, 100% Compose
- SharedPreferences 기반 객체 직렬화(JSON 문자열) 저장 및 객체 리스트 관리 로직으로 구현한 "좋아요" 기능 구현
